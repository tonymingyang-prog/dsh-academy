Automation
每 3 天，自动巡检与发布
两条互相独立的自动化链路：本机计划任务负责开发机上的刷新，GitHub Actions 负责公网仓库的定时构建。任一条都能单独工作。

      

      

        

          
 Windows 计划任务

          
注册 DSHAcademy-Refresh 每 3 天 03:00 巡检并构建；登录启动项会在后台拉起 4173 预览服务。

          

    
powershell

    
powershell -ExecutionPolicy Bypass -File deploy\register-tasks.ps1
schtasks /Query /TN "DSHAcademy-Refresh" /V /FO LIST

  

        

        

          
 GitHub Actions

          
仓库内置 .github/workflows/update-and-deploy.yml：cron 每 3 天抓取、构建并发布到 Pages，push 时也会跑一次。

          

    
yaml

    
on:
  schedule:
    - cron: "0 3 */3 * *"
  workflow_dispatch:
  push:
    branches: [main]

  

        

      

    

  

  

    

      

        
Guides
四条部署路径
所有命令都在 Windows PowerShell 下验证过；Linux/macOS 去掉 $env: 前缀即可。

      

      

        

          
 本机 / 内网

          
构建后以零依赖静态服务器托管，后台启动并写入 PID。适合团队内网、演示与离线环境。

          

    
powershell

    
npm run build
npm run deploy -- --target local --port 4173
# 打开 http://127.0.0.1:4173

  

        

        

          
 GitHub Pages

          
通过 Git Data API 把 dist/ 写成一次提交，不需要本地 git。推送到 gh-pages 后在仓库设置里启用 Pages。

          

    
powershell

    
$env:GITHUB_TOKEN = "ghp_xxx"
$env:GITHUB_REPO = "your-name/dsh-academy"
npm run build
node scripts/deploy.mjs --target github --branch gh-pages

  

        

        

          
 Docker

          
多阶段构建：Node 里生成静态产物，Nginx 托管。镜像不包含源码与爬虫，体积小、重启即恢复。

          

    
powershell

    
npm run build
docker build -t dsh-academy .
docker run -d --name dsh-academy -p 8080:80 --restart unless-stopped dsh-academy

  

        

        

          
 Netlify

          
打包 dist/ 后调用 Deploy API，适合已有 Netlify 站点或需要预览环境。

          

    
powershell

    
$env:NETLIFY_AUTH_TOKEN = "xxx"
$env:NETLIFY_SITE_ID = "xxxxxxxx-xxxx"
npm run build
node scripts/deploy.mjs --target netlify

  

        

      

    

  

  

    

      

        

          
环境变量

          
GITHUB_TOKENGitHub PAT（repo）

          
GITHUB_REPOowner/name

          
NETLIFY_AUTH_TOKEN个人访问令牌

          
NETLIFY_SITE_ID站点 ID

          
SITE_BASE_PATH子路径，如 /dsh-academy/

          
PORT本地服务端口

        

        

          
发布前验收

          
巡检数据完整（npm / releases / docs）必过

          
构建退出码为 0，search-index 可解析必过

          
首页 / 课程 / FAQ / 更新 四页可访问必过

          
移动端 390px 无横向滚动建议

          
视频与字体本地化，无外部 CDN已内置

        

      

      
密钥只放在环境变量或 CI Secrets 中。部署脚本不会把 token 写入任何文件；构建产物里也不包含凭据。
