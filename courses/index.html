完整学习路线

8 个模块按依赖顺序排列。前四门把 Harness 用顺手，后四门把它接进团队流程并部署上线。建议每门课动手跑一遍命令，再读「常见坑」。

LESSON 01 入门

安装与首次启动

从零启动 DSH Web UI，选中工作区并完成第一次带工具调用的任务。学完你能判断启动失败是 Node 版本、端口占用还是模型未配置。

模型与凭据配置

会话、上下文与目标

理解 DSH 的会话日志、上下文压缩和同会话目标，让长任务跑得久而不跑偏。学完你能在上下文快满时正确压缩，并用 /goal 让 agent 自动续跑。

工具、审批与沙箱
